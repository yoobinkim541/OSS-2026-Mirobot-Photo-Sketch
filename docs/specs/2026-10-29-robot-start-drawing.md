# 실물 로봇 시작 자세 및 드로잉 명세

## 목표
앱에서 로봇을 연결하고 호밍 완료를 확인한 뒤, 저장된 대기 자세로 이동하고 종이 중심 접촉 자세를 기준으로 그림을 그린다.

## 확정된 기준
- 호밍 직후 기준: J1~J6 0° (컨트롤러 상태 Idle 및 관절값 확인).
- 대기 자세: [0, 0, 0, 0, -128, 0]°.
- 종이 중심 접촉 자세: [0, 10, -12, 0, -128, -3]° (기존 사용자 측정; 설치 변경 시 재확인).
- 종이 보정은 120×120 mm 한 경로만 사용한다.
- 장착 펜의 홀더 오프셋과 새 대기 자세의 종이 간격은 미검증이다.

## 기능 요구사항
1. 호밍과 대기 자세 이동은 명확한 단계로 표시하고 실제 컨트롤러 응답을 확인한다. 연결 해제, 알람, 시간 초과 시 후속 명령을 보내지 않는다.
2. 호밍은 기기의 리밋과 영점 설정을 변경하지 않는다. 호밍 동작의 관절별 특성은 실기 확인 전 가정하지 않는다.
3. 대기 자세까지의 경로는 실제 펜·홀더와 주변을 반영하여 검증하고 각 단계 도착 후 관절값을 확인한다. 실제 조건 미검증 시 이동을 차단하고 이유를 표시한다.
4. 종이 중심 및 방향은 접촉 자세의 실제 TCP와 자세를 사용한다. 단순 호밍 기준 0° 자세를 접촉 자세에 적용하지 않는다.
5. 실행 명령과 사전 시뮬레이션은 같은 출발 관절, 자세, 좌표계 및 경로를 사용한다. 오류 시 그림을 시작하지 않는다.
6. 실기 공중 이동 및 접촉 테스트는 사용자 감독 하에 진행한다. 센서가 없는 환경에서 접촉력은 검증할 수 없다.

## 완료 기준
- 정상, 취소, 컨트롤러 오류 및 위치 불일치에 대한 자동 테스트 통과.
- 실제 경로와 시뮬레이션 자세의 일치가 검증됨.
- 실기 호밍, 대기 자세, 공중 경로 및 접촉 시험이 각각 기록됨.

## 1단계 확인 결과 (2026-10-29)
컨트롤러의 기존 두 샘플을 관절값으로 FK 계산해 TCP 위치를 비교했다. 이전 대기 자세의 모델 오차는 X -0.201, Y -0.012, Z +0.323 mm, 접촉 자세는 X -0.195, Y -0.012, Z +0.326 mm였다. 두 점의 위치 일치는 확인했으나 컨트롤러의 회전각 정의 및 새 대기 자세의 실제 TCP는 아직 검증하지 못했다. 이 결과만으로 실기 충돌이나 접촉력을 보장하지 않는다.

## 2단계 구현 결과 (2026-10-29)
컨트롤러 Rx/Ry/Rz를 Rz·Ry·Rx 회전으로 적용한 뒤 모델 홈 회전에 곱하면 두 실측 관절 샘플의 회전과 약 0.001° 이내로 일치한다. 시뮬레이터는 실행 설정의 orientation_deg와 선택적 simulation_start_joints_deg를 사용한다. 이는 수학 및 두 샘플에 대한 검증이며 실제 전체 경로의 안전성 검증이 아니다. 실물 드로잉 차단과 미검증 홀더 오프셋은 유지한다.

## 이동 중 관찰 방식 (2026-10-29 사용자 결정)
사용자가 실물 이동 동안 펜과 홀더의 경로를 직접 관찰한다. 관찰은 홀더 3차원 좌표를 검증한 것으로 기록하지 않는다. 이동 중 위험을 발견했을 때 물리 정지 버튼을 사용할 수 있어야 하며, 현 앱의 취소는 이미 전송한 이동을 즉시 멈추지 않으므로 이 한계를 사용자에게 명시한다.

## 사용자가 정한 실행 순서 (2026-10-29)
주변 확인 후 호밍된 로봇을 1번 대기 자세로 이동한다. 그리기 시작을 누르면 2번 종이 접촉 자세로 이동하고 각 획 사이에 접촉점 기준 10 mm 후퇴해 이동한다. 완료 후 1번 대기 자세로 돌아간다. 사용자가 이동 전 과정을 직접 관찰한다.

## 실물 연결 경로 (2026-10-29)
가상 실행과 같은 순서(호밍 → 1번 대기 자세 → 시작 확인 → 2번 접촉 자세 → 그리기 → 1번 대기 자세 → 호밍 자세(관절 0))가 실물 연결에도 연결되어 있다. 호밍 자세로 돌아가는 길은 시작할 때의 경로를 거꾸로 밟는다(옆으로 돌기 → 옆에서 손목 풀기 → 정면). 다음 그림은 포트를 다시 열 때 보드가 리셋되므로 호밍 버튼을 한 번 더 누르면 같은 자리에서 바로 시작한다. 실물 검증 전에는 포트를 열기 전 ① 사전 검사에서 멈추고 이유를 표시한다.
- 멈추는 조건: `tool_offset_verified`가 false, 또는 1번 자세 펜 간격 실측과 모델이 3 mm 넘게 다름, 또는 "다시 보정"과 함께 켬.
- 위 조건이 풀리면 실행 전에 "로봇 이동 확인" 창에서 주변 확인과 정지 버튼 준비를 묻는다.
- 펜 접촉 범위(limits) 검사는 접촉 자세로 움직이기 전에 한다. 범위를 벗어나면 종이에 닿지 않고 멈춘다.
- 공중 모드는 접촉 자세로 가지 않고 기록된 접촉 샘플 기준 좌표로 펜을 뗀 채 따라간다.
- 펜을 내릴 때는 접촉점보다 `requested_pen_down_extra_mm`만큼 더 누른다(2026-10-29 사용자 요청으로 1 → 7 mm). 펜업 높이(10 mm)와 느린 접근 구간(2.5 mm)은 누른 점이 아니라 종이 면에서 잰다: 더 깊이 눌러도 종이 앞 2.5 mm부터 느리게 닿고, 획 사이에는 종이에서 10 mm 떨어진다.

## 1번 자세 간격과 접촉 자세 (2026-10-29 확인)
1번(0,0,0,0,-128,0)과 2번(0,8,-8,0,-128,0)은 J2+J3가 같아 손목 방향이 같고, 로봇은 X로 15.03 mm, Z로 -1.05 mm 평행 이동만 한다(FK, 컨트롤러 응답과 0.3 mm 이내). 펜 홀더 모양과 상관없이 펜 끝도 똑같이 15.0 mm 움직인다. 사용자가 확인한 두 사실(2번에서 펜이 닿음, 1번 간격 18 mm)은 간격을 펜 방향(플랜지 z, 종이 면과 38°)으로 잰 값이면 일치한다: 15.03 / cos 38° = 19.1 mm.
따라서 종이 면은 설정의 `wall_distance_mm`(270, 추정값)가 아니라 2번 자세의 펜 끝으로 정하고, 1번 간격 검사는 펜 방향 길이로 비교한다. 사용자가 이 값을 확인해 로컬 설정의 `tool_offset_verified`를 true로 바꿨다. 오프셋 값 자체는 사진 추정이며, 시작 자세로 옆으로 도는 경로는 사용자가 지켜본다.
