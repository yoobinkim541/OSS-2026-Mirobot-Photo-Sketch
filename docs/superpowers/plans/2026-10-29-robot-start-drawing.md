# 로봇 시작 자세 및 드로잉 구현 계획

> 단계별로 테스트를 먼저 추가하고 가상 로봇에서 확인한다.

**목표:** 호밍 후 대기·접촉 자세를 연결하고 동일 좌표계로 그림을 실행한다.
**명세:** docs/specs/2026-10-29-robot-start-drawing.md
**구성:** 기존 start_pose, draw_job, draw_executor, mirobot_sim 및 GUI를 단계별로 수정한다.
**환경:** Python, NumPy, unittest, WLKATA Studio 및 Mirobot.

## 단계
- [x] 실제 컨트롤러 좌표계와 시뮬레이터 자세 변환 검증: 기존 TCP·관절 상태 샘플로 오차와 축 순서를 검증한다.
- [x] 동일한 출발 자세와 방향을 실행기·시뮬레이터에 전달하고 기존 홈 기준 동작 회귀 테스트를 수행한다.
- [x] 호밍 확인 및 저장된 대기 자세 이동을 앱 연결 흐름에 추가한다. 각 응답, 위치 불일치 및 취소 테스트를 작성한다.
- [x] 접촉 자세와 종이 중심 좌표를 반영하고 종이 보정 및 드로잉을 해당 좌표계에 연결한다.
- [x] 가상 로봇의 정상 및 실패 경로를 통합 검증한다. 실물 연결 경로는 검증 전 포트를 열기 전에 멈춘다.
- [ ] 실물에서 리밋·홀더·이동 경로를 확인하고 공중 및 접촉 시험을 기록한다. (펜 홀더 오프셋·1번 자세 간격 재측정 필요)

## 검토 포인트
하드 리밋 반복, 호밍 실패, 시리얼 시간 초과, 관절 위치 불일치, 실물 펜 접촉 과압.
