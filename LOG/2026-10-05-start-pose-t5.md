# 2026-10-05 — 시작 자세 T5: 그리기 창에서 자동 이동 + 누르고 있는 동안 조그 + 기억하고 계속

## 사용자 요청

- 손으로 팔을 움직여 위치를 가르치는 방식(직접 교시)을 물어봄 → Mirobot은 엔코더 없는 스테핑 모터라 손으로 움직이면 컨트롤러가 위치를 모름(전원마다 호밍 필요). 대신 **조그로 움직이고 기억하는 방식**을 앱 화면에 넣기로 함.
- 위·아래(Z)로도 움직일 수 있게 해 달라고 함 → "Z 고정" 조건을 없앰(펜 자세 A·B·C 고정은 유지).

## 만든 것

- `start_pose.StartPoseSetup` (작업 스레드 `run()`, 화면 스레드 `jog()`·`accept()`·`cancel()`), 직각 홀더 전용:
  1. 호밍 자세(관절 0° ± 0.5°)인지 확인. 저장된 시작 자세가 있으면 **펜을 뒤로 뺀 채(펜올림 높이 10 mm) 그 높이·좌우로 옮긴 뒤 앞으로 다가가** 자동으로 그 자리로. 이미 그 자리(1 mm 이내)면 움직이지 않음. 호밍 자세도 저장 자세도 아니면 거부.
  2. 조그: 요청을 한 번에 하나만 받고 바쁘면 버림(누르고 있는 동안 화면이 150 ms마다 보내도 밀리지 않고, 손을 떼면 곧 멈춤). A·B·C는 기준 자세 값 고정, 허용 상자(기준에서 X −30~+60, Y ±60, Z ±60 mm) 밖은 보내지 않음.
  3. 기억하고 계속: `check_ready` 통과 시 설정 파일 `start_pose.ready_pose`에 저장하고 그 TCP를 이번 실행의 종이 중심으로 씀. 실패하면 이유를 화면에 보이고 계속 기다림.
- `check_ready`: Z 변화 거부를 없앰. 로봇을 뒤로 옮길 거리 찾기 간격 5 → 10 mm(검사 시간 단축).
- 명령줄 조그 `r`/`f` = 위/아래 추가.
- `DrawJob.start(..., start_pose=True)`: ②호밍 뒤 ③에서 위 단계를 실행. `job.jog(dx, dy, dz)`, `job.accept_start_pose()`. 멈춤·취소는 그대로 동작(결과 `cancelled`). 다시 보정을 고르면 쓰지 않음.
- 그리기 창:
  - 옵션 "호밍 뒤 시작 자세 맞추기 (기억한 자세로 자동 이동, 조그로 고치기)" — 기본 켜짐, **실제 로봇에만** 적용(가상 시뮬레이션은 예전처럼).
  - ③에서 조그 패널: 벽 쪽(W) / 뒤로(S) / ◀ 왼쪽(←) / 오른쪽 ▶(→) / ▲ 위(↑) / ▼ 아래(↓), 버튼은 **누르고 있는 동안 계속**, 키보드는 자동 반복으로 계속. 한 번에 0.5 / 2 / 10 mm. 현재 펜 위치(플랜지) 표시. [이 위치 기억하고 계속].
  - 끝난 뒤 되돌리기는 기존 "끝나면 펜을 처음 위치(종이 중심)로 되돌리기"가 기억한 시작 자세로 돌아감.
- 테스트: `tests/test_start_pose_setup.py` 7개, `test_draw_job` 2개, `test_gui_smoke` 1개(가상 로봇으로 ▲ 누르고 있기 → 기억 → ④ 최종 확인까지; 기억 버튼을 무력화하면 실패함을 확인). 전체 439개 통과(1개 건너뜀).

## 확인하지 못한 것 (실물)

- 직각 홀더로 단 펜으로 호밍 → 조그 → 기억 → 그리기 → 시작 자세 복귀 전체.
- 저장 자세로 자동 이동할 때의 실제 궤적(뒤로 빼기 → 옆·높이 → 앞으로).
- 조그 이동 속도(approach 200 mm/min)가 손으로 맞추기에 적당한지.

## 2026-10-06 추가: 명령줄 조그를 Enter 없이 키 하나로

- 사용자: CMD 창에서 키를 입력하고 Enter를 쳐야 움직이는 게 불편함 → 키를 누르면 바로 움직이게.
- `start_pose.console_keys()`: Windows 콘솔에서 `msvcrt`로 키 하나씩 읽음(방향키는 두 글자로 들어와 Up/Down/Left/Right로 바꿈). 콘솔이 아니면(파이프 등) 예전처럼 한 줄씩.
- 키는 그리기 창과 같게: W/S 벽 쪽·뒤로, ←/→ 좌우, ↑/↓ 위아래(a/d, r/f, x도 됨), 1·2·3 이동량, Space 현재 좌표, Enter 검사 후 저장, Q·Esc 끝.
- 누르고 있으면 운영체제 자동 반복으로 계속 움직이고, 한 칸마다 그동안 쌓인 반복 키를 버려 손을 떼면 바로 멈춘다.
- 테스트 5개 추가(키 이동·저장·끝, 콘솔이 아닐 때 줄 단위로, 방향키 이름). 앞의 3개는 새 코드 없이 실패 확인, 콘솔 판별 2개는 구현 뒤 작성. 전체 444개 통과(1개 건너뜀).
- 실물 콘솔에서 직접 눌러 보지는 못했다(도구 환경은 콘솔이 아님).
