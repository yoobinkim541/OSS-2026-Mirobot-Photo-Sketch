# 2026-09-28 — 5점 접촉 캘리브레이션과 사각형 범위 탐색

## 결정한 절차

- 종이와 벽 사이의 간격은 사람이 맞춘다. 중심을 홈 TCP에 두고 종이를 고정한 뒤, 프로그램이 접촉 여부를 자동 판정한다고 가정하지 않는다.
- 펜을 종이에서 약 5 mm 띄우고 60×60 mm 사각형의 변을 차례로 따라간다. 사용자는 각 꼭짓점에서 간섭·충돌·비정상 소음을 확인한다. 확인된 크기에서 멈추거나, 현재의 `limits` 한계까지 한 변 10 mm씩 확장한다.
- 선택한 중심과 네 모서리에서 X축 접촉값을 수집한다. 각 모서리는 벽 쪽/후퇴 방향으로 0.25 mm씩 조정하며, 사용자가 막 닿았다고 판단할 때 저장한다. 예측 접촉보다 0.5 mm 넘게 누르는 명령은 막는다.
- 다섯 지점의 X 편차에 최소제곱 평면을 맞춰 `a_per_mm_y`, `b_per_mm_z`를 산출한다. 최대 잔차가 1 mm 이하여야 중심·평면 보정값·실물 허용 사각형을 갱신한다. 실패하거나 사용자가 취소하면 기존 설정을 유지한다.
- 로봇이 상태 조회와 TCP는 보고하지만 종이 접촉은 감지할 수 없으므로, 이 과정에는 웹캠이 필요하지 않고 접촉 확인은 사람이 한다.

## 구현

- `mirobot_sketch/calibration.py`: 계획 출력, 사람 확인형 펜업 사각형 이동, 다섯 지점 측정, X 평면 적합, 잔차 검증, 원자적 설정 저장과 전체 보고서 저장을 추가했다.
- `mirobot-calibrate` 명령을 추가했다. 기본 실행은 범위만 출력하고, `--execute`를 줘야 시리얼 포트를 한 번 열고 수동 호밍 뒤 로봇을 움직인다.
- GUI 또는 `mirobot-draw --execute`에서 보정값이 없는 상태로 처음 실물 연결을 할 때 동일한 측정 절차를 안내한다. 사용자는 GUI 다이얼로그 또는 터미널에서 범위 진행/중단과 0.25 mm 접촉 조그를 입력한다. GUI는 보정 완료 후 드로잉 경로와 관절 시뮬레이션을 새 보정값으로 다시 확인한다. 가상 로봇에서는 측정하지 않는다.
- 성공한 측정은 `robot/drawing_config.json`의 중심·평면 보정·정사각형 한계를 바꾸며, 결과는 `LOG/calibrations/calibration-*.json`에 저장한다. 설치 실행에서는 사용자 설정 폴더에 기록한다.
- README에 동작 순서와 수동 접촉 확인 방식을 적었다.

## 검증 및 상태

- `tests/test_calibration.py`: 평면 기울기 복원, 비평면 잔차 거부, 허용 사각형 검사, 사용자 취소 시 무동작, 가짜 링크로 전체 5점 측정, 원자적 설정 저장을 검사한다.
- 전체 회귀 테스트: **292개 통과, 1개 건너뜀** (Windows에서 bash가 필요한 검사). 이후 CLI 실물 연결 자동 보정 추가까지 포함해 캘리브레이션 테스트 15개, 드로잉 실행기 테스트 21개, 첫 실물 연결 DrawJob 테스트 1개를 다시 실행해 모두 통과했다. GUI 스모크 테스트는 통과했으며, 창 종료 뒤 `after` 콜백 진단이 일부 출력되는 기존 동작은 남아 있다.
- 캘리브레이션 사각형의 가상 관절 검사: 60×60, 70×70, 80×80, 90×90, 100×100 mm 모두 PASS (X 후퇴 5 mm). 이는 기구학 시뮬레이션 결과이며 실물 확인을 대체하지 않는다.
- 기본 CLI 계획은 반폭 [30, 35, 40, 45, 50] mm, 즉 60×60부터 100×100 mm까지를 출력하고, 계획 모드에서는 COM 포트를 열지 않는다.
- 테스트된 크기는 소프트웨어상의 최대 실물 허용 범위까지이며, 이 세션에서는 실제 로봇을 움직이지 않았다.
- 이전 실물 연결 점검에서 COM9 열기가 `FileNotFoundError`로 실패했다. 따라서 현재 종이 평면이나 최대 사각형 크기는 측정되지 않았고 `robot/drawing_config.json`도 캘리브레이션에 의해 변경되지 않았다.
- 별도 제한: `paper_x_to_robot_y_sign`의 방향은 이 대칭 사각형 검사만으로 확인할 수 없다. 그림 방향 검증에는 비대칭 `orientation-test-F.json` 시험이 계속 필요하다.

## 다음 실행

저장소 루트의 Windows 터미널에서 `python -m mirobot_sketch.calibration`으로 계획을 확인한 뒤 `python -m mirobot_sketch.calibration --execute`를 실행한다. 포트를 점유하는 다른 프로그램은 닫고, 로봇의 중앙 버튼으로 직접 호밍한다. 펜업 경로가 불안하거나 종이 접촉이 애매하면 `q`로 취소하고, 종이를 다시 고정한 뒤 반복한다. 성공 후 작은 사각형의 G-code를 먼저 dry-run하고, 공중 모드로 경로를 확인한 다음 실제 드로잉을 재개한다.
