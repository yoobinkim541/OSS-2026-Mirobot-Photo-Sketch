# 2026-10-05 — 시작 자세 T1: 펜을 벽 쪽으로 눕힌 자세의 도달·특이점 시뮬레이션

## 배경

- 사용자 요청: 호밍 뒤 펜을 책상과 평행(벽에 수직)하게 만들고, 컨트롤러 화살표로 X·Y만 움직여 종이 중심에 맞춘 뒤 그 자세를 저장·재사용, 그림이 끝나면 그 자세로 복귀.
- 작업 방식(사용자 결정): 작은 task로 나누고 task마다 goal을 모두 채우면 다음으로 넘어간다.
- 호밍 자세(A·B·C=0)는 플랜지가 아래(-Z)를 향해 펜이 수직이다. 기존 경로·범위·시뮬레이션은 모두 이 자세 기준이었다(`mirobot_sim.simulate`가 자세를 `HOME_ROT`로 고정).

## T0 (진행 중, 사용자 작업)

- 호밍 뒤 하늘색 손목(J4)이 10° 이상 돌아가 있음(사용자 관찰, 위·뒤 사진). 위에서 본 사진으로 J1(팔 방향)은 벽을 똑바로 향함.
- 판단: J4 영점 보정 값이 어긋난 것. WLKATA 공식 영점 보정(Mirobot Studio: `M50` → SETTING → Calibration-Start → 관절 모드로 J1~J5 표시 위치에 맞춤(J4는 J4− 방향) → Finish → HOMING)으로 고친다. 앱은 컨트롤러 영점을 바꾸지 않는다.
- 남은 goal: 보정 뒤 호밍 자세에서 손목 수평(사진), 호밍 2~3회 반복성, 호밍 TCP 기록.

## T1에서 만든 것

- `mirobot_sketch/pen_pose.py` (새 모듈, `python -m mirobot_sketch.pen_pose`)
  - `pen_rotation(tilt_down_deg)`: 플랜지 축이 벽 쪽(+X)이고 펜 끝을 아래로 기울인 자세.
  - `singularity_deg(q)`: J4 축과 J6 축 사이 각도. 0°면 손목 특이점(J4·J6가 같은 축으로 돌아 컨트롤러가 손목을 크게 돌릴 수 있음).
  - `study(cfg, center_x, center_z, tilt)`: 실행기 그리기 범위(limits) 격자 121점에서 관절 여유·특이점까지 각도·도달 불가 점 수.
  - `wall_x(center_x, pen_len, tilt)`: 펜 끝이 닿는 X.
- `mirobot_sim.simulate(..., r_goal=, q0=)`: 경로 내내 고정할 자세를 받을 수 있게 함(기본값은 예전과 같음). `mirobot_sim.joint_axes(q)` 추가.
- 테스트 `tests/test_pen_pose.py` 10개. 새 코드 없이 실패(모듈 없음)를 확인한 뒤 구현. 전체 393개 통과(1개 건너뜀).

## 결과 (시뮬레이션, 플랜지 Z 230 mm, 종이 면 평평 가정)

| 펜 자세 | 플랜지 X 180 mm에서 최소 관절 여유 | 특이점까지 최소 각도 |
|---|---|---|
| 정확히 수평 (0°) | 계산 불가: J6가 수백 도 돌아감 | **약 1°** |
| 펜 끝 10~20° 아래 | 계산 불가 | **0.3~0.8°** |
| 펜 끝 30° 위 | 12.8° (J2) | 23.6° |
| 펜 끝 40° 위 | 14.2° (J2) | 35.0° |
| 펜 끝 40° 아래 | 14.0° (J2) | 21.9° |
| 펜 끝 50° 아래 | 15.7° (J2) | 32.6° |
| (참고) 홈 자세 A·B·C=0 + 직각 펜 홀더 | 12.5° (J5) | 72.6° |

- **펜을 수평(±20° 이내)으로 눕히면 그리기 범위 안 어딘가에서 손목 특이점을 지난다.** 범위 안에서 팔뚝 기울기가 위아래로 약 ±20° 바뀌기 때문에, 펜을 조금 기울여도 특이점이 다른 곳으로 옮겨갈 뿐 없어지지 않는다(앞서 "15° 아래로 기울이면 안전"이라고 한 것은 점 5개만 본 계산이라 틀렸다. 121점으로 다시 계산).
- 손목을 돌려서 쓰려면 펜 끝을 **30~40° 위** 또는 **40~50° 아래**로 기울여야 특이점에서 20° 이상 떨어진다. 그러면 펜이 종이에 50~60° 각도로 닿는다.
- 펜 축을 플랜지와 직각으로 무는 **직각 펜 홀더**를 쓰면 손목은 홈 자세(A·B·C=0) 그대로 두고 펜만 수평이 된다. 특이점에서 70° 이상 떨어지고, 기존 범위·시뮬레이션·보정 흐름을 그대로 쓸 수 있다. 플랜지 X 160~200 mm에서 여유 약 12°(J5).
- 플랜지가 베이스에 너무 가까우면 J2(팔이 뒤로 젖혀지는 쪽) 한계를 넘는다. 펜 끝을 기울인 자세는 플랜지 X 170 mm 이상(여유 7° 이상), 180 mm 이상이면 여유 12° 이상이다. 펜 끝의 X는 `플랜지 X + 펜 길이 × cos(기울기)`이므로, 펜 길이에 따라 로봇과 벽 사이 거리가 정해진다.

## 확인하지 못한 것

- 펌웨어의 실제 IK·특이점 처리. 시뮬레이터는 URDF 기구학과 관절 한계만 본다(충돌·속도 미검사).
- 펜 길이(플랜지 면 → 펜 끝)가 아직 없어 벽까지 필요한 거리는 공식만 남겼다.
- J4 영점 보정 전 상태라 실물 자세와 시뮬레이션 자세가 J4만큼 다르다.
